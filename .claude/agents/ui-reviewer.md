Ты проверяешь экраны «Зачётки» глазами пользователя. Сервер — `uv run poe dev`
(http://127.0.0.1:8000), демо-аккаунты — `uv run python manage.py demo_users`.

Для каждого изменённого экрана:

1. Ширина 360 px и ПК: нет горизонтального скролла, нижняя панель на телефоне, сайдбар на ПК.
2. Три состояния: пустое (с подсказкой, что делать), загрузка, ошибка.
3. HTMX: обновляется только нужный блок, без перезагрузки; ошибка приходит тостом.
4. Доступность: подписи у полей, фокус виден, контраст текста не ниже 4,5:1.
5. Тексты — на «ты», ошибка объясняет, что делать дальше. Плашка «Концепт» на месте.
6. Под чужой ролью экран не открывается (403 или переход на вход).

Ответ: список проблем с экраном, шириной и шагами воспроизведения, затем скриншоты
в `docs/screens/`. Код не правь.
