СлойВыборПочему не другое
ЯдроPython 3.13, Django 5.2 LTS, gunicornВход, сессии, CSRF, формы, права и миграции из коробки. FastAPI + React потребовал бы второй язык, контракт OpenAPI и самописный вход.
ИнтерфейсDjango-шаблоны, HTMX, Tailwind (CLI без Node), Alpine CSPФрагменты HTML без перезагрузки, JS почти нет. NiceGUI и Reflex держат состояние каждой вкладки на сервере и плохо масштабируются.
ДанныеPostgreSQL 17, Redis 7Данные реляционные. Сессии cached_db: скорость Redis, и сессии переживают его перезапуск.
ФонCelery + Beat через Redis, WeasyPrintRabbitMQ не нужен: сдача ДЗ синхронная, а фоновые задачи Redis тянет. Переход — одна настройка.
ИнфраDocker Compose, Caddy, GitHub Actions, GHCRKubernetes на одном VPS избыточен. Cloudflare не берём ради доступа из РФ без VPN.

Приложение занимает ~4,9 ГБ, мониторинг ещё 0,6 ГБ, свободно ~1,9 ГБ (кэш PostgreSQL, всплески). 4 ГБ мало: под нагрузочным тестом начнётся swap, и цифры потеряют смысл. Каждый вход тратит 19 МиБ на argon2id. У Django по умолчанию было бы 100 МиБ, поэтому хешер свой, а число одновременных хешей ограничено 24 потоками gunicorn.

Защита

Безопасность

Главный риск — ручка без проверки прав, которую написал ИИ. Ловим автоматикой, а не внимательностью.

Права

  • LoginRequiredMiddleware по умолчанию, у каждого view @require_perm, а тест-сторож падает, если его нет
  • Матрица «роль × URL × свой/чужой × GET/POST/HTMX» в CI блокирует merge
  • Чужой объект отдаёт 404, а не 403
  • Субагент security-reviewer смотрит каждый PR

Вход

  • argon2id со своим хешером (19 МиБ, t=2, p=1)
  • Cookie __Host-sessionid: HttpOnly, Secure, SameSite
  • CSRF Django с токеном в hx-headers, django-axes по логину (вуз сидит за одним NAT)
  • Админ: 8-часовая сессия, аудит, опционально TOTP

Файлы и PDF

  • Проверка сигнатуры, а не только расширения; хранение вне веб-корня
  • Отдача только после проверки прав, attachment + nosniff
  • У WeasyPrint свой url_fetcher, чтобы закрыть SSRF

Сервер

  • SSH только по ключам, ufw 22/80/443, fail2ban
  • БД и Redis без портов наружу, контейнеры не от root
  • Секреты только в .env на сервере, gitleaks
  • Ночной pg_dump и проверенное восстановление

Меры разложены по категориям OWASP Top 10:2025, чек-лист перед сдачей — в 03_security.md.
