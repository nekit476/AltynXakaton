## Главное на одном экране

- **Стек (решение 04.11):** монолит на Django 5.2 LTS (Python 3.13).
  - Интерфейс: Django-шаблоны + HTMX + Tailwind (Alpine.js для мелочей).
  - Данные и фон: PostgreSQL 17, Redis 7 (кэш, сессии и брокер), Celery.
  - Сервер и доставка: Caddy, Docker Compose, GitHub Actions.

  Отдельного фронта на JS и RabbitMQ нет, почему — в [02_architecture.md](02_architecture.md#отвергнутые-варианты).
- **VPS:** 4 vCPU / 8 ГБ RAM / 80 ГБ NVMe в российском дата-центре (Timeweb Cloud, Selectel, REG.RU). Сервисы занимают ~4,9 ГБ, с мониторингом ~6,1 ГБ, остальное — запас и кэш ОС.
- **Нагрузка, на которую рассчитываем:** 15 тыс. пользователей (в Губкинском ~10 тыс. очных студентов), 3 тыс. одновременно, 300 RPS устойчиво и 500 RPS пиками; p95 < 300 мс.
- **Роли:** студент, преподаватель, администратор. Права проверяются на сервере и на уровне каждого объекта; доступ к чужим данным покрыт автотестом-матрицей.
- **Команда:**
  - A «Платформа и качество» — Никита;
  - B «Учебная логика» (модели, сервисы, Celery);
  - C «Интерфейс и продукт» (шаблоны, HTMX, дизайн, PDF).
- **Этапы:**
  - S0 «Старт» (4–5.11);
  - S1 «Скелет» (6–8.11);
  - S2 «Ядро» (9–12.11);
  - S3 «Преподаватель и админ» (13–16.11);
  - S4 «Вау и полировка» (17–19.11, вечером 19-го заморозка функций);
  - S5 «Тесты и выпуск» (20–22.11).
