Как

Работа с Claude

Что использую

  • Навык new-service — сигнатура и DTO → тесты на правила → реализация → обновить контракт для C
  • Навык db-migration — миграция + проверка отката на копии сидера + makemigrations --check
  • Агент test-writer — сначала тесты на бизнес-правила (parametrize, hypothesis), потом код
  • Контракт — services.py/selectors.py с заглушками на данных сидера — по ним C верстает, не дожидаясь тебя
