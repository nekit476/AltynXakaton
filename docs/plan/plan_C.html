Работа с Claude

Что использую

  • Навык new-screen — view с require_perm → шаблон и фрагмент → 3 состояния → проверка на 360 px → скриншот
  • Агент ui-reviewer — открывает страницу в браузере на 360 px и на ПК, проверяет состояния, контраст, HTMX-обновления
  • Прототипы — варианты экранов через Claude (artifacts / Design) до вёрстки, неудачные — в PDF
  • Логотип и иллюстрации — ИИ-генератор + доработка вручную, без копирования вузовского знака
