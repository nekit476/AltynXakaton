# web/ — участник 3 (C): интерфейс и продукт

Views, URL, шаблоны, HTMX-фрагменты, компоненты, статика.

## Views

- Тонкие: права → вызов селектора или сервиса из `domain.<app>` → шаблон.
- Импортировать из `domain` можно только `services`, `selectors`, `forms`, `dto`. Модели и менеджеры — нельзя (это проверяет `tests/test_architecture.py`).
- На HTMX-запрос (`request.htmx`) отдаётся фрагмент `<раздел>/_partials/...`, на обычный — страница целиком.
- `core.errors.NotFound` → 404, а не 403.
- Каждый новый URL вносится в матрицу прав (задача #24): GET, POST и HTMX-вариант.

## Шаблоны и статика

| Где | Что |
|---|---|
| `templates/base.html` | Каркас страницы: плашка «Концепт», `noindex` |
| `templates/ui/` | Компоненты дизайн-системы (#19): кнопка, карточка, бейдж, пустое состояние, тост, модалка |
| `templates/<раздел>/`, `templates/<раздел>/_partials/` | Страницы и HTMX-фрагменты |
| `static/css/`, `static/js/`, `static/vendor/` | Стили (Tailwind — #19), `app.js`, htmx и Alpine CSP с зафиксированными версиями, без CDN |

- У каждой страницы и фрагмента три состояния: пустое, загрузка, ошибка.
- Мобильная версия начинается с 360 px, без горизонтального скролла.
- Никаких `|safe`, `mark_safe`, inline-скриптов и `hx-on`. CSRF-токен — в `hx-headers` на `<body>`.
- Тексты обращаются к пользователю на «ты», ошибки объясняют, что делать дальше.
