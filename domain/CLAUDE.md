# domain/ — участник 2 (B): учебная логика

Модели, менеджеры, сервисы, селекторы, формы, задачи Celery, сидер. Ничего не знает о `web/`.

## Приложения

`org` · `schedule` · `courses` · `assignments` · `grades` · `requests` · `notifications` · `seed` — в каждом `__init__.py` написано, что в нём живёт и какие задачи бэклога его касаются.
Новое приложение: папка с `apps.py` (`name = "domain.<имя>"`, `label = "<имя>"`) и строка в `DOMAIN_APPS` в `core/settings/base.py`.

## Слои внутри приложения

| Файл | Что | Правило |
|---|---|---|
| `models.py` | Данные | Ссылка на пользователя — `settings.AUTH_USER_MODEL`. У объектов, которые попадают в URL, — `UUIDField` |
| `managers.py` | Менеджеры с областью видимости | `for_student(user)`, `for_teacher(user)`: через них идёт любое чтение |
| `dto.py` | Результаты для `web` | `@dataclass(frozen=True)`, не модели |
| `selectors.py` | Чтение | Первый аргумент — `user`, выборка ограничена им. Чужой или несуществующий объект → `core.errors.NotFound` |
| `services.py` | Запись | То же. Транзакция — явный `transaction.atomic`, задачи — через `on_commit` |
| `forms.py` | Валидация бизнес-правил | Явный `fields = [...]` |
| `tasks.py` | Celery | `@shared_task`, идемпотентно: повтор не шлёт уведомление второй раз |
| `templates/<app>/` | Только шаблоны справок PDF (`requests`) | Интерфейсные шаблоны — в `web/` |

**Контракт для C** — сигнатуры селекторов и сервисов с DTO. Сначала заглушки на данных сидера, затем реализация (задача #7).
Сигнатуру, которую уже использует `web`, не меняем молча: новые параметры добавляются в конец, новые поля — в DTO.

## Ошибки

Свои ошибки наследуются от `core.errors.AppError` (`AssignmentClosed(AppError)` и т. п.), контекст передаётся атрибутами.
Чужое исключение заворачивается через `raise ... from exc`.

## Тесты

В `tests/domain/<app>/`. Правила — [tests/CLAUDE.md](../tests/CLAUDE.md).
Бизнес-правила (штраф за опоздание, конфликты переноса, окна напоминаний) — параметризованные тесты, сначала тест, потом код.
